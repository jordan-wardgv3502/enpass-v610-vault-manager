## What is Enpass?

Enpass provides an organized way to manage passwords and other sensitive information while retaining a strong emphasis on local control. Data is stored in an encrypted vault that can remain available across devices through synchronization when multi-device access is needed.

The application supports personal and team workflows, including online and offline use, quick form completion, and routine account sign-ins. Multilingual operation and biometric authentication also make it suitable for a wide range of desktop and mobile scenarios.

---

## Key capabilities

- Store passwords and private information in a locally focused encrypted vault
- Synchronize vault data between multiple devices
- Fill login fields and web forms automatically
- Unlock the vault with biometric authentication on compatible devices
- Access locally stored data offline through a zero-knowledge, offline-first model
- Use the application in multiple languages
- Support premium-oriented workflows for advanced account and vault usage
- Run across supported desktop and mobile environments

## Getting started

1. Launch Enpass, then create a vault or unlock an existing one.
2. Save passwords, notes, and other credentials in the encrypted vault.
3. Enable synchronization when the vault should be shared across devices.
4. Use autofill through supported browsers and applications for logins and forms.
5. Turn on biometric access when the device provides compatible support.
6. Review and update stored items as your accounts and preferences evolve.

## Settings and configuration

Enpass handles most configuration through its in-app preferences. These controls include vault behavior, synchronization, autofill, and authentication options.

A representative configuration layout is:

    vault:
      sync: enabled
      autofill: enabled
      biometric: enabled
      language: auto

Open the application settings panel to tailor these options to the device and workflow in use.

## Frequently asked questions

**How can I obtain updates?**  
Follow the download link above to look for the newest build and available version updates.

**Where does Enpass keep its settings?**  
Most preferences are managed within the application. Vault-related information follows Enpass's encrypted storage model.

**What should I check when synchronization fails?**  
Verify the account configuration, network connection, and device permissions. Also make sure synchronization is enabled in Enpass.

**Why is autofill unavailable?**  
Confirm that integration with the browser or application is active and that the required permissions have been granted.

**Does Enpass work without an internet connection?**  
Yes. Its offline-first vault model allows local access without continuous connectivity.
